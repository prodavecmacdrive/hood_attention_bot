# 🤖 Telegram Monitoring Bot

Интеллектуальный бот для мониторинга Telegram каналов с ML-фильтрацией, системой обратной связи и оптимизацией по районам.

## 🌿 Ветки репозитория

### 📦 `main` - Чистый код (текущая)
- Исходный код без данных
- Для разработки и деплоя
- БД и модели не включены

### 🧠 `trained-model` - С обученной моделью
- **Содержит:** БД с ML примерами + обученная модель
- **Для:** Продакшн использования с готовыми данными
- **Синхронизация:** Сохраняйте прогресс обучения

```bash
# Использовать готовую обученную модель:
git clone <repo_url>
git checkout trained-model
python main.py  # БД уже с примерами!
```

> 📖 Подробнее о работе с trained-model: [TRAINED_MODEL_BRANCH.md](https://github.com/prodavecmacdrive/hood_attention_bot/blob/trained-model/TRAINED_MODEL_BRANCH.md)

## ✨ Возможности

- 📊 **Статистика** - подробная аналитика работы бота

## 🚀 Быстрый старт

### Требования

- Python 3.8+
- Telegram аккаунт с номером телефона
- API ключи от Telegram

### 1. Установка

```bash
# Клонируйте репозиторий
git clone <repository_url>
cd attantion_bot

# Создайте виртуальное окружение
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows

# Установите зависимости
pip install -r requirements.txt
```

### 2. Настройка

1. Получите API ключи:
   - Перейдите на https://my.telegram.org
   - Войдите с номером телефона
   - API Development Tools → Создайте приложение
   - Скопируйте `api_id` и `api_hash`

2. Создайте бота:
   - Напишите @BotFather в Telegram
   - Создайте бота командой `/newbot`
   - Скопируйте токен

3. Создайте файл `config.py` на основе `config.example.py`:
```bash
cp config.example.py config.py
```

4. Заполните `config.py`:
```python
API_ID = 12345678
API_HASH = "your_api_hash"
PHONE = "+380123456789"
BOT_TOKEN = "bot_token_from_botfather"
```

### 3. Первый запуск

```bash
python main.py
```

При первом запуске:
1. Введите код из Telegram (придет SMS)
2. Если есть 2FA - введите пароль
3. Напишите боту `/start`
4. Следуйте инструкциям мастера настройки

## 🧠 Как работает ML

### 1. Обучение на примерах

Когда вы пересылаете боту сообщение:
1. Текст преобразуется в вектор (embedding) - 384 числа
2. Вектор сохраняется в базу данных
3. При новом сообщении вычисляется схожесть (cosine similarity)
4. Если схожесть > 75% → сообщение отправляется вам

### 2. Негативные примеры

Нажимая 👎 на нерелевантном сообщении:
1. Создается embedding негативного примера
2. При проверке новых сообщений:
   - Если схожесть с негативным > 85% → **БЛОК**
   - Если позитивное < 80% И негативное > 70% → **БЛОК**
3. Это решает проблему ложных срабатываний

**Пример:**
- ✅ "РСЗО по області" - релевантно
- ❌ "РСЗО по області в режимі ПВО" - нажимаете 👎
- Теперь похожие сообщения блокируются автоматически!

### 3. Оптимизация по районам

Когда админ запускает `/admin_optimize`:
1. Собираются данные всех пользователей района
2. **Ключевые слова** - топ-20 по частоте использования
3. **ML примеры** - кластеризация (K-means) → 10 лучших примеров
4. Пользователи могут переключиться на "Optimized" режим

```
main.py          # Основная логика бота
├── database.py  # Работа с SQLite

```

### База данных

- `channels` - отслеживаемые каналы
- `keywords` - ключевые слова
- `user_keywords` - личные слова пользователей
- `user_examples` - позитивные ML примеры
- `user_negative_examples` - негативные примеры (дизлайки)
- `districts` - 61 район
- `user_settings` - настройки пользователей (район, режим)
- `district_optimized_keywords` - оптимизированные слова района
- `district_optimized_examples` - оптимизированные ML примеры района
- `district_optimization_log` - история оптимизаций

## 🛠️ Технологии

- **Telethon** - Telegram MTProto API
- **sentence-transformers** - ML модель для embeddings
  - Модель: `paraphrase-multilingual-MiniLM-L12-v2`
  - Поддержка русского/украинского языков
  - 384-мерные векторы
- **scikit-learn** - K-means кластеризация
- **RapidFuzz** - нечеткий поиск районов
- **SQLite** - локальная база данных (WAL mode)

## 🐛 Troubleshooting

**Ошибка авторизации:**
```
FloodWaitError: A wait of X seconds is required
```
Решение: Подождите X секунд, Telegram ограничивает частоту запросов.

**ML модель не загружается:**
```
ConnectionError: Can't download model
```
Решение: Модель скачается автоматически при первом запуске (1-2 минуты).

**База данных заблокирована:**
```
database is locked
```
Решение: Закройте все экземпляры бота, проверьте `*.db-wal` файлы.
