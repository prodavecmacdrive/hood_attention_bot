# 🤖 Telegram Monitoring Bot

Інтелектуальний бот для моніторингу Telegram каналів з ML-фільтрацією, системою зворотного зв'язку та оптимізацією по районах.

## ✨ Можливості

- 📺 **Моніторинг каналів** - відстежує декілька каналів одночасно
- 🔑 **Ключові слова** - фільтрація за словами та фразами
- 🤖 **ML-пошук** - семантичний пошук схожих повідомлень (sentence-transformers)
- 👍👎 **Зворотний зв'язок** - лайки/дизлайки для навчання системи
- 🚫 **Негативні приклади** - автоматичне блокування хибних спрацювань
- 🗺️ **Оптимізація по районах** - колективне навчання для кожного району
- 🔄 **Два режими** - особисті дані або дані району
- 📊 **Статистика** - детальна аналітика роботи бота

## 🚀 Швидкий старт

### Вимоги

- Python 3.8+
- Telegram акаунт з номером телефону
- API ключі від Telegram

### 1. Встановлення

```bash
# Клонуйте репозиторій
git clone <repository_url>
cd attantion_bot

# Створіть віртуальне оточення
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows

# Встановіть залежності
pip install -r requirements.txt
```

### 2. Налаштування

1. Отримайте API ключі:
   - Перейдіть на https://my.telegram.org
   - Увійдіть з номером телефону
   - API Development Tools → Створіть додаток
   - Скопіюйте `api_id` та `api_hash`

2. Створіть бота:
   - Напишіть @BotFather в Telegram
   - Створіть бота командою `/newbot`
   - Скопіюйте токен

3. Створіть файл `config.py` на основі `config.example.py`:
```bash
cp config.example.py config.py
```

4. Заповніть `config.py`:
```python
API_ID = 12345678
API_HASH = "your_api_hash"
PHONE = "+380123456789"
BOT_TOKEN = "bot_token_from_botfather"
```

### 3. Перший запуск

```bash
python main.py
```

При першому запуску:
1. Введіть код з Telegram (прийде SMS)
2. Якщо є 2FA - введіть пароль
3. Напишіть боту `/start`
4. Слідуйте інструкціям майстра налаштування

- `🤖 ML Приклади` - керування прикладами

**Зворотний зв'язок:**
- 👍 - корисне повідомлення

**Режими роботи:**

## 🧠 Як працює ML

### 1. Навчання на прикладах

Коли ви пересилаєте боту повідомлення:
1. Текст перетворюється у вектор (embedding) - 384 числа
2. Вектор зберігається в базу даних
3. При новому повідомленні обчислюється схожість (cosine similarity)
4. Якщо схожість > 75% → повідомлення відправляється вам

### 2. Негативні приклади

Натискаючи 👎 на нерелевантному повідомленні:
1. Створюється embedding негативного прикладу
2. При перевірці нових повідомлень:
   - Якщо схожість з негативним > 85% → **БЛОК**
   - Якщо позитивне < 80% І негативне > 70% → **БЛОК**
3. Це вирішує проблему хибних спрацювань

**Приклад:**
- ✅ "РСЗО по області" - релевантно
- ❌ "РСЗО по області в режимі ПВО" - натискаєте 👎
- Тепер схожі повідомлення блокуються автоматично!

### 3. Оптимізація по районах

Коли адмін запускає `/admin_optimize`:
1. Збираються дані всіх користувачів району
2. **Ключові слова** - топ-20 за частотою використання
3. **ML приклади** - кластеризація (K-means) → 10 кращих прикладів
4. Користувачі можуть переключитись на "Оптимізований" режим

### База даних

- `channels` - канали що відстежуються
- `keywords` - ключові слова
- `user_keywords` - особисті слова користувачів
- `user_examples` - позитивні ML приклади
- `user_negative_examples` - негативні приклади (дизлайки)
- `districts` - 61 район
- `user_settings` - налаштування користувачів (район, режим)
- `district_optimized_keywords` - оптимізовані слова району
- `district_optimized_examples` - оптимізовані ML приклади району
- `district_optimization_log` - історія оптимізацій

## 🛠️ Технології

- **Telethon** - Telegram MTProto API
- **sentence-transformers** - ML модель для embeddings
  - Модель: `paraphrase-multilingual-MiniLM-L12-v2`
  - Підтримка російської/української мов
  - 384-вимірні вектори
- **scikit-learn** - K-means кластеризація
- **RapidFuzz** - нечіткий пошук районів
- **SQLite** - локальна база даних (WAL mode)

## 🐛 Вирішення проблем

**Помилка авторизації:**
```
FloodWaitError: A wait of X seconds is required
```
Рішення: Почекайте X секунд, Telegram обмежує частоту запитів.

**ML модель не завантажується:**
```
ConnectionError: Can't download model
```
Рішення: Модель завантажиться автоматично при першому запуску (1-2 хвилини).

**База даних заблокована:**
```
database is locked
```
Рішення: Закрийте всі екземпляри бота, перевірте `*.db-wal` файли.
